# 💱 Conversor de Real para Dólar em Python

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido em Python com o objetivo de converter um valor em reais (R$) para dólares (US$), com base na cotação informada pelo usuário.

## 📄 Descrição

O programa solicita ao usuário:

* O valor atual do dólar
* Um valor em reais

Com base nesses dados, o sistema realiza o cálculo da conversão e exibe o resultado formatado com duas casas decimais.

A fórmula utilizada é:

```id="calc1"
dolares = reais / valor_do_dolar
```

O projeto utiliza conceitos básicos da programação em Python, como:

* Entrada de dados (`input`)
* Conversão de tipos (`float`)
* Operações matemáticas
* Função `round()` para formatação de números
